# GrowIntern Projects

This repository contains a collection of machine learning and data science projects developed as part of the GrowIntern program. Each project is contained in its own subdirectory with detailed documentation.

## Projects

### 1. Car Price Predictor (`CarPricePredictor/`)
A machine learning application that predicts car prices based on various features such as mileage, year, engine size, and more. Built using Linear Regression and Streamlit for an interactive web interface.

### 2. Stock Price Prediction (`StockPricePrediction/`)
An LSTM-based neural network model for predicting stock prices, specifically designed for Apple stock data over the past 20 years. Features interactive visualizations and performance metrics using Streamlit.

## Technologies Used
- **Python**: Primary programming language
- **Streamlit**: For building interactive web applications
- **Machine Learning Libraries**: Scikit-learn, Keras, TensorFlow
- **Data Processing**: Pandas, NumPy
- **Visualization**: Matplotlib
- **Model Serialization**: Pickle, Keras models

## Getting Started
Each project has its own README with detailed installation and usage instructions. Navigate to the respective project directory to get started.
